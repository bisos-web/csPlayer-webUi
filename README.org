* Overview

=http://csPlayerUi.here= brings the BISOS command-service players together in one site. Its first
player, the /csPlayer CSXU/ tab, is webCliGui (=cliGui/webCliGui=): a React application that builds,
executes and monitors CSXU command lines, here as an *Astro island* --- rendered into the site's page,
under its tabs, on its origin --- instead of an iframe of =csLineInvoker.here=.

The site is built from =bisos-web/astro-starter-bystar= (the =astro-site= activity): its pages come
from =content/tree/=. The earlier Gatsby site, which framed webCliGui and Airflow and coordinated them
through a postMessage bus, is kept in =gatsby/=.

*Status (2026-10-18)*: webCliGui runs as an island and logs in against its backend, csPlayerPerf
(=bisos-web/csPlayerPerf-drf=, a capability of its own), which this site's vhost proxies at =/api/=,
=/admin/= and =/static/=. The header shows the csPlayer context (user, package, module); the CSXU pages
follow it; Airflow and Grafana are links. Not yet: the CSXU Graphviz page.

* webCliGui as an Island

| Piece                           | What it does                                                   |
|---------------------------------+----------------------------------------------------------------|
| =content/tree/csPlayer/=        | an =app= node: the tab, its title and place                    |
| =site/src/pages/csPlayer.astro= | the tree's layout, with =<WebCliGui client:only="react" />=    |
| =site/src/apps/webCliGui/=      | =WebCliGui.tsx= (its root component, as its =main.tsx= renders |
|                                 | it) and =webCliGui.css= (its stylesheet, plus =@source=)       |
| =site/package.json=             | =webcligui: file:/bxRepos/cliGui/webCliGui=, React 19,         |
|                                 | react-bootstrap, zustand, Tailwind v4, =@astrojs/react=        |
| =site/astro.config.mjs=         | webCliGui's aliases, =preserveSymlinks= and =dedupe=           |
|                                 | (one React), =@icons/*.svg= served =?url=                      |

webCliGui's source is not changed. What the integration needed, each solved on the site's side:

- *Its imports resolve from the site*: =preserveSymlinks= makes =react-bootstrap=, =zustand=, ...
  resolve from =site/node_modules=; =dedupe= keeps one React.
- *Tailwind did not see its classes*: its source is under =node_modules=, which Tailwind v4's
  detection skips; =webCliGui.css= imports its =index.css= and adds =@source= for its =src/=.
- *Its icon rendered as =[object Object]=*: webpack made an image import a URL string, Astro makes it
  an image object; the =@icons/*.svg= alias adds =?url=.
- *Its global CSS (Bootstrap)* would restyle the site's own header, tabs and footer on its page: the
  site's chrome is styled by class (=.frame=, =.siteFooter code=, ...), which Bootstrap's element
  rules cannot override. Its CSS is loaded only on its own page.

* The csPlayer Context

One small store, =site/src/lib/csPlayerContext.ts=, holds the current user, the selected package and
the selected module; it replaces the Gatsby site's message bus, iframe adapter and orchestration
store.

- *Shown* in the header's context bar on every page (=unset= until set), by a few lines of script in
  the layout; React islands read it with =useCsPlayerContext()=.
- *Written* by webCliGui, unchanged: it posts =csPlayer:packageChanged= and =csPlayer:filterChanged=
  to =window.parent=, which for an island is the page's own window, where =installBridge()= takes them
  (=csPlayer:userChanged= too, for when webCliGui reports its user; it holds only a JWT today). And by
  the address: =?package=bisos.facter&csxu=facter.cs=.
- *Kept* in =localStorage= (=bisos-orchestration-storage=, the Gatsby site's key), so it carries
  across pages and browser tabs.
- *Verified* (2026-10-18) by driving headless Chrome over its DevTools protocol: on the csPlayer page,
  the two messages as webCliGui sends them moved the header from =unset= to the package and module,
  and were stored.

| Tab or page           | What it is                                           |
|-----------------------+------------------------------------------------------|
| csPlayer CSXU         | webCliGui, an island (=app= node)                    |
| CSXU / CSXU Info      | the package's =README.org= from GitHub (island)      |
| CSXU / Python Sources | the module's =py3/bin/<module>= from GitHub (island) |
| CSXU / pipx Info      | the package on PyPI (island)                         |
| Grafana               | a =link= node: =http://grafana.here/= in a new tab   |

The CSXU islands' Tailwind is loaded without its base reset, and with its utilities outside any
cascade layer: a layered rule loses to every unlayered one, so the site's =pre { background }= had
beaten =.bg-gray-900=.

* Usage

#+begin_src bash
./astroProc.spcs -i siteBuild                 # content, npm ci, astro build
./astroProc.spcs -i siteVerify / /csPlayer/   # 200s and the site's 404
(cd site && npx astro dev --host 127.0.0.1 --port 25001)
cd /bisos/platform/sys/cbm/collective/hereWeb/csPlayerUi && ./cbmProc.spcs -i cbm_materialize
#+end_src

To change webCliGui and see it here: edit it in =/bxRepos/cliGui/webCliGui= (linked), rebuild this
site (or run =astro dev=).
