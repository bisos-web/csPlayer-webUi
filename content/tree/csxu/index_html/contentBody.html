These pages follow the package and module selected on the csPlayer CSXU tab, shown in the header. Each fetches from the sources at run time, from your browser:

  • CSXU Info --- the package's README.org, from GitHub;
  • Python Sources --- the module's file, py3/bin/<module>;
  • pipx Info --- the package on PyPI.

A selection can also be named in the address, e.g. ?package=bisos.facter&csxu=facter.cs.
