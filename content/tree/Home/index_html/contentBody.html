csPlayer brings the BISOS command-service players together in one site. Its first player, csPlayer CSXU, is webCliGui (cliGui/webCliGui): a React application that builds, executes and monitors CSXU command lines.

Here webCliGui is not framed: it is an Astro island, a React component rendered into this page, under this site's tabs, on this site's origin. See About for what that means and how it differs from the earlier Gatsby site, which framed it (now in gatsby/).
